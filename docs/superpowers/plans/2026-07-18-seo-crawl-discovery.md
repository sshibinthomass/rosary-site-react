# SEO Crawl Discovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every public product strong crawlable internal links from its category, catalogue card, and related product pages without changing its SEO identity or canonical URL.

**Architecture:** Extend the existing SEO artifact pipeline with deterministic related-product link enrichment derived only from public products. The same generated metadata feeds static HTML and hydrated React, while category artifact pages remove their 50-product presentation cap and ProductCard exposes a semantic product link.

**Tech Stack:** Node.js test runner, React 19, React Router 7, Vite, existing SEO artifact generator.

## Global Constraints

- Preserve canonical URL construction, redirects, sitemap policy, robots directives, product identity content, pricing, imagery, and Firebase data.
- Related products are public/indexable, exclude self, prefer matching category and subcategory, are deterministic, and are capped at six.
- Do not add runtime Firestore catalogue reads or new routes.
- Preserve the existing product-card presentation and purchase controls.
